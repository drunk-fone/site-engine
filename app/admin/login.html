Erzeuge auf dem Server einen Einmal-Link:

kubectl exec -it deploy/<name> -n <namespace> -- python /app/server.py reset-admin

Lokal: python3 app/server.py reset-admin

Passwort vergessen? Mit python /app/server.py reset-admin auf dem Server einen neuen Einmal-Link erzeugen.
